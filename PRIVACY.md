# Privacy

OPFS Inspector collects no data and sends nothing anywhere.

It reads and changes files in the origin private file system of the page you inspect, only when you open its panel in the developer tools and act in it. Everything stays in your browser. It has no analytics and makes no network requests.

It keeps only your panel settings, in the extension's own storage. When you open a SQLite database, the copy it reads is kept in memory only, and is gone when you close the panel.
